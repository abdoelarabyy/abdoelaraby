# Abdo Elaraby Portfolio

This is the latest standalone HTML version of the portfolio supplied in the conversation.

## Deploy with GitHub + Vercel
1. Create a new GitHub repository.
2. Upload `index.html` to the repository root.
3. Import the repository into Vercel (or connect it to the existing Vercel project).
4. No build command is required for this standalone static HTML version.
5. Set the output directory to `.` if Vercel asks for one.

## Notes
- The website is delivered as a single self-contained HTML file.
- Fonts and some media/content are loaded from external URLs referenced by the HTML.
- This package does not include the older CMS/admin/Supabase project. That project is a separate, older version and should not be mixed with this latest HTML without a compatibility update.
